# Codex project guidance

Read and follow [`CLAUDE.md`](CLAUDE.md). It is the canonical repository guide; do
not duplicate its contents here. Project documentation is indexed in
[`docs/README.md`](docs/README.md).

Never commit personal notes, local machine paths, note frontmatter, wiki links,
credentials, or real personal data into this public repository.

Repository files may describe both approved requirements and a provisional scaffold.
Only treat something as a team decision when the repository records evidence of that
approval. If repository documentation and the original project sources conflict,
surface the conflict without silently choosing one.

Do not treat prior personal choices, proposals, or the existing scaffold as project
requirements. Original supplied documents and later formally recorded approvals are
the only sources that can authorize a technology, scope, or workflow choice.
