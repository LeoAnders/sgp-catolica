# Decisoes de arquitetura (ADRs)

Cada decisao tecnica acordada pela equipe vira um arquivo numerado nesta pasta:
`ADR-001-titulo-da-decisao.md`.

Modelo minimo:

```markdown
# ADR-001: Titulo curto da decisao

## Contexto

Qual problema ou duvida tecnica motivou a decisao.

## Decisao

O que a equipe decidiu fazer.

## Consequencias

O que a escolha facilita, o que custa ou limita.
```

Nenhum ADR foi registrado ainda. Propostas individuais so entram aqui depois de
acordadas pela equipe.
