# Documentacao do projeto

Documentacao oficial do SGP Catolica. O que esta aqui vale como fonte para a equipe;
rascunhos e ideias em discussao ficam fora do repositorio ate serem acordados.

| Pasta | Conteudo |
| --- | --- |
| `produto/` | Visao do produto, personas, requisitos e escopo de cada fase. |
| `design/` | Design system, mapa de telas e fluxos de navegacao. |
| `decisoes/` | ADRs (Architecture Decision Records) das decisoes ja tomadas pela equipe. |
| `telas/` | Prints das telas, referenciados pelo README. |
| `uml/` | Diagramas de casos de uso, classes e atividades. |
| `arquitetura/` | Diagramas de arquitetura e camadas. |
| `modelo-dados/` | MER/DER e dicionario de dados. |
| `api/` | Especificacao de endpoints e colecoes de teste. |

As pastas vazias entram no repositorio com um `.gitkeep` e serao preenchidas conforme
as fases avancam.
